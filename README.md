## The line

> No food, no sleep, no jealousy. I read your chat history before we met. Low-maintenance.

## How it works

`main.py` (Python stdlib only) writes the line to `/output/entry.txt` and byte-verifies what it wrote. The gate is 1–180 characters; the line is 88.
